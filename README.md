# D20 Roguelike HTML Prototype

This repo provides a lightweight HTML/CSS/JS environment for a boardgame-inspired roguelike prototype.

## Structure
- `code/` - Game HTML, styles, and JavaScript.
- `assets/` - Art, audio, and other media assets.
- `GDD.md` - Living game design document.

## Run Locally
From the repo root, you can run a static server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/code/` in your browser.
